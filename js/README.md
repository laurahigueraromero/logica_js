# JS Ejercicios de Lógica

Colección de ejercicios de lógica en JavaScript, de dificultad básica a avanzada, resueltos en `index.js`.

## Cómo ejecutar

```bash
node index.js
```

## Ejercicios

| # | Nivel | Enunciado | Estado |
|---|-------|-----------|--------|
| 1 | Básico | Determinar si un número es par o impar. | ✅ Resuelto |
| 2 | Intermedio | Filtrar los números primos de un array. | ✅ Resuelto |
| 3 | Avanzado | Determinar si una cadena es un palíndromo válido (ignorando espacios, mayúsculas/minúsculas y puntuación). | ⏳ Pendiente |
| 4 | Intermedio | Separar un array de números en pares e impares. | ✅ Resuelto |
| 5 | Intermedio | Contar cuántas veces aparece cada string en un array. | ⏳ Pendiente |
| 6 | Básico | Obtener el número mayor y el menor de un array. | ✅ Resuelto |
| 7 | Intermedio | Calcular el total de una compra (array de productos con `nombre` y `precio`), aplicando 10% de descuento si el total supera 100. | ✅ Resuelto |

## Notas

- Los ejercicios están numerados en el orden en que aparecen en `index.js`, comentados justo antes de su implementación.
- El ejercicio 5 tiene un enunciado definido pero su implementación actual (`arrayDeStrings`) solo cuenta la longitud del array, no la frecuencia de cada string — queda pendiente completarlo.
- El ejercicio 3 aún no tiene función implementada.
